Last updated: 13 November 2026

This Privacy Policy describes the publicly accessible project information website at https://matrasz.github.io, operated under the project name Affiliate AI Robot PRO. It does not yet describe a live TikTok-connected application. This page must be revised before any integrated service launches.

The current static website does not have account registration, contact forms, analytics scripts, trackers installed by the project, or an API backend. We do not ask for or receive TikTok passwords, TikTok access tokens, or affiliate sales data through this website.

The pages are hosted using GitHub Pages. GitHub may process technical and usage data as described in its own privacy statement. Any external link you follow is subject to that destination's practices.

The project is in development. This public site does not connect to TikTok or process TikTok user data. The current static website does not maintain a project-controlled database of visitors. The project does not sell visitor information. GitHub's own hosting logs and retention are governed by GitHub.

For non-sensitive questions or requests to improve this policy, use the project repository issues. This is a public channel: do not post personal or confidential information. 6. Updates

Changes will be published here with a revised effective date. No future data processing is authorized by this draft policy alone.
