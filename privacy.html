Privacy and data handling

Privacy Policy

Last updated: 13 November 2026

This policy applies to the public site at https://matrasz.github.io and its current interactive Content Studio Demo. This website does not currently provide a live TikTok-connected account service. A separate offline Python demonstration program may be run on a local computer. It does not connect to TikTok or receive credentials.

1. Data you enter

All product selections, audience descriptions, feature notes, and generated drafts in the Studio Demo are processed in your browser using JavaScript. The site does not transmit these inputs to our servers or to TikTok. It does not provide account creation, forms, tracking analytics, or a database managed by the project.

2. Downloads and browser state

The demo may allow you to download or copy drafts. The resulting files are saved by your browser on your own device. This version does not use cookies or localStorage to save user inputs.

3. Hosting and third parties

GitHub Pages hosts these public files. GitHub may collect technical request information according to GitHub's privacy practices. External links are governed by their respective operators.

4. Optional offline Python demonstration

The separately supplied Python demonstration produces content drafts on the local device. It does not connect to TikTok, request TikTok authentication, collect access tokens or send personal data to the project website. No automated publishing is provided.

5. Purpose and user choice

The web demo provides content drafting examples. Any future live TikTok integration must require the user's explicit consent, use only permitted scopes, explain how any account data is handled, and offer a disconnect path. This site does not currently collect TikTok user profile, post, commission, or sales data.

6. Retention and deletion

No drafts or profile data are retained by the website operator from the current demo. You can close the page and delete any locally downloaded files. The optional offline Python demo writes a draft TXT file to the local computer if used; delete this file whenever you wish. Note that third-party platforms may retain their own records under their policies.

7. Contact and future changes

Non-sensitive website feedback can be sent through public project issues; please never include private information there. A confidential contact method and an expanded policy must be published before offering a live account-connected service to users. We will update this policy if our processing activities change.
