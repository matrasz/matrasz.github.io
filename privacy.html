Privacy Policy

Last updated: 13 November 2026

This policy covers the publicly accessible project website at https://matrasz.github.io, including its in-browser draft studio. The website is an independent prototype; it is not a TikTok login service, live affiliate marketplace, or TikTok posting integration. These terms must be updated before any actual user-account integration is launched.

1. Data entered in the Studio

The page processes the product selections, target-audience text, notes, and any CSV file you choose to import with JavaScript in your browser. CSV imports are limited to product planning data; you should not upload personal or sensitive information. The project does not transmit that content to its own servers or to TikTok. This version does not use a project-managed database, account-registration forms, analytics scripts, or advertising trackers.

2. Drafts and poster downloads

When you choose to download text, CSV, or a PNG poster, the browser creates a local file on your own device. Using your browser's copy function may put content on your local clipboard. This site does not use localStorage or cookies to retain draft inputs. Refreshing the page can discard unsaved inputs.

3. Hosting

GitHub Pages serves the publicly accessible files. GitHub and your browser or network provider may process technical information such as IP addresses and request metadata under their own policies. The project does not control those independent practices.

4. Optional Python application

The separately distributed Windows Python package works locally with product CSV files, optional images you select, generated text, and video files. These materials are saved under a local output directory on your own computer. The current program does not request TikTok account credentials, connect to TikTok, read affiliate accounts, or publish content. Dependencies installed on your computer are governed by their respective terms.

5. Security and user choices

Do not include private tokens, passwords, identifying details, or unauthorized product images in content or CSV files. You control and may delete your local downloads and output folder. The website currently holds no project-managed user account records to export or delete.

6. Changes and contact

If TikTok authorization, server storage, AI cloud processing or analytics is later implemented, a new privacy policy will need to describe the exact data categories, purposes, retention, deletion and user controls before launch. For general project feedback, visit the public GitHub repository; do not post private information in public issues.
